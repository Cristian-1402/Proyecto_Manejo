# Proyecto Jordan 1 - Landing Page (Release 1.0.0)

**Universidad Técnica de Ambato | Facultad de Ingeniería en Sistemas, Electrónica e Industrial**

## Descripción del Proyecto
Desarrollo de una Landing Page interactiva enfocada en la presentación del calzado Air Jordan 1 Retro High OG. Este proyecto académico tiene como objetivo principal la aplicación práctica de diseño web modular, maquetación semántica, diseño responsivo y trabajo colaborativo mediante control de versiones.

## Características de la Versión 1.0.0
* **Navegación y Hero:** Estructura semántica con encabezado responsivo e imagen de alto impacto visual.
* **Presentación del Producto:** Sección detallada con información, identificadores (SKU) y descripción general de las Air Jordan 1.
* **Especificaciones Técnicas:** Grid informativo destacando materiales y tecnología del calzado mediante tarjetas interactivas.
* **Galería Visual:** Componente de imágenes interactivas con sistema de filtrado modular por perspectivas (Frontal, Lateral, Detalles).
* **Selector de Modelos:** Visualización de variantes de colores e interacción de selección.
* **Estructura Base:** Integración de pie de página (Footer) y llamados a la acción (CTA) consistentes con la identidad visual.

## Tecnologías Utilizadas
* HTML5 (Estructura semántica).
* CSS3 (Arquitectura de hojas de estilo modulares).
* JavaScript (Lógica de componentes interactivos).
* Framework: Bootstrap 5 (Sistema de grillas y utilidades).

## Arquitectura y Control de Versiones
El proyecto mantiene un alto estándar de organización mediante la separación de recursos gráficos (assets/), hojas de estilo segmentadas (css/) y scripts (js/). 

Para el flujo de trabajo colaborativo, el equipo ha implementado:
* **Modelo GitFlow:** Uso estricto de ramas principales (main, develop) y ramas derivadas para características (feature/).
* **Conventional Commits 1.0.0:** Trazabilidad estandarizada en el historial mediante prefijos (feat, style, fix, docs, chore).
* **Integración y Revisión:** Fusión de código habilitada únicamente a través de Pull Requests auditados con un mínimo de dos aprobaciones cruzadas.

## Ejecución Local
Al ser un proyecto estático basado en el lado del cliente (Frontend), no requiere instalación de dependencias ni ejecución de servidores de desarrollo complejos.
1. Clonar el repositorio localmente.
2. Navegar a la carpeta raíz del proyecto.
3. Abrir el archivo index.html en cualquier navegador web moderno.
